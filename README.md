# Appunti di Governance e Diritto delle Pubbliche Amministrazioni

Raccolta personale di appunti, schede normative e note di giurisprudenza.

## Struttura

| Cartella | Contenuto |
|---|---|
| `01-fonti-e-principi` | Costituzione (artt. 97, 98, 117, 118), fonti, principi dell'azione amministrativa |
| `02-organizzazione-amministrativa` | Enti, organi, competenze, autonomie territoriali, D.Lgs. 165/2001 (organizzazione) |
| `03-procedimento-e-atti` | L. 241/1990, provvedimento, vizi, autotutela, accesso, silenzio |
| `04-contratti-pubblici` | D.Lgs. 36/2023, affidamenti, PNRR |
| `05-trasparenza-e-anticorruzione` | L. 190/2012, D.Lgs. 33/2013, ANAC, PTPCT |
| `06-performance-e-controlli` | D.Lgs. 150/2009, PIAO, controlli interni, Corte dei conti |
| `07-digitalizzazione` | CAD (D.Lgs. 82/2005), AgID, interoperabilità, dati |
| `08-pubblico-impiego` | Lavoro pubblico, dirigenza, contrattazione |
| `09-responsabilita` | Responsabilità amministrativa, contabile, disciplinare, erariale |
| `giurisprudenza` | Schede di sentenze (Cons. Stato, TAR, Corte cost., Corte dei conti) |
| `templates` | Modelli per nuovi appunti |
| `risorse` | Link utili, bibliografia |

Vedi anche [`glossario.md`](glossario.md).

## Convenzioni

- Un file Markdown per argomento, nome in minuscolo con trattini: `silenzio-assenso.md`
- Citare le norme nella forma `art. 21-octies L. 241/1990`
- Partire da un modello in `templates/`
