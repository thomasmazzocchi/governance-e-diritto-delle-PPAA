# Governance e Diritto delle PPAA – Diritto amministrativo (GEPID)

Appunti per l'esame di Diritto amministrativo del **7 gennaio 2027**.
Testo: B.G. Mattarella, *Lezioni di diritto amministrativo*, Giappichelli, 3ª ed.
