# Governance e Diritto delle PPAA – Diritto amministrativo (GEPID)

Appunti per l'esame di Diritto amministrativo del **7 gennaio 2027**.
Testo: B.G. Mattarella, *Lezioni di diritto amministrativo*, Giappichelli, 3ª ed.

Uno schema per capitolo (o paragrafo) del Mattarella, tutti sul modello [`templates/schema-capitolo.md`](templates/schema-capitolo.md). Quando il testo del libro non è disponibile, lo schema lo dice all'inizio e va confrontato con il libro.
