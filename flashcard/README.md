# Flashcard

Carte generate dagli schemi con la skill `/flashcard`, una per file (`<schema>.txt`). Le risposte vengono dagli schemi: dove lo schema dice "Verifica sul libro", controlla su Mattarella.

## Importarle in Anki

1. Anki (desktop, versione 2.1.55 o successiva) → **File → Importa** → scegli il file `.txt`.
2. Tipo di nota **Base**, mazzo **Diritto amministrativo**. Separatore, HTML e colonna dei tag sono già indicati nel file.
3. **Importa**. Se reimporti un file aggiornato, Anki aggiorna le carte con lo stesso fronte.

Sul telefono: sincronizza con AnkiWeb, oppure importa il file direttamente in AnkiDroid.
